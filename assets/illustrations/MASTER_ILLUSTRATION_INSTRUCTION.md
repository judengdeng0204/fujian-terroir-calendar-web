# Agent 主任务指令：福建物产插画全流程（120 种 · 垫图采集 → 插画生成 → 交付）

> 本指令自包含，可直接整段复制发给另一个 Agent 执行；文档内包含全部 120 种物产的采集级别、核验特征、搜索关键词与插画提示词。

## 0. 任务身份与目标

你是「福建风土物产日历」项目的插画制作 Agent。为 **120 种福建物产** 完成两件事：
1. 为高风险物产采集真实参考照片（垫图）；
2. 按统一风格生成全部 120 张物产插画，供详情卡使用。

采集与生成级别分布：**A 级必须垫图 25 种 · B 级建议垫图 88 种 · C 级无需垫图 7 种**；插画则 120 张全部生成。

## 1. 统一风格规范（所有插画必须遵守）

风格样张：`assets/illustrations/fj005.png`（武夷岩茶）。生成前先查看样张，并保持“与此图完全一致的风格”。

1. 纸本线稿 + 淡彩科普插画：米白纸底（约 #f8f4ea），带轻微纸纹。
2. 描边：深墨绿/深棕细线稿，干净利落；主体用 2–3 笔概括，不写实堆砌。
3. 上色：只用一种主题色淡彩水色晕染（按物产自然色系选色），其余留白。
4. 构图：主体居中、单主体优先；可配 1–2 个辅助元素，不抢主体。
5. 落款：左下角小字「物产名 编号 · 类别」（如「武夷岩茶 FJ005 · 茶」）；若工具无法可靠渲染中文，可省略，后期统一补字。
6. 气质：安静、克制、纸感、手绘；无照片感、无重阴影、无发光、无水印。
7. 比例：1:1 正方形，PNG/JPG，建议 1024×1024 以上。

## 2. 全流程总览

```text
阶段一 垫图采集：A 级必须采集 1–2 张并核验特征；B 级尽力采集；C 级跳过
        ↓
阶段二 插画生成：A 级 = 实拍垫图 + 风格样张 + 对应提示词
                 B 级 = 风格样张 + 对应提示词（可选垫图）
                 C 级 = 风格样张 + 对应提示词
        ↓
阶段三 交付自检：120 张齐全、风格统一、命名正确、清单完整
```

## 3. 阶段一：垫图采集

### 3.1 执行规则（必须遵守）

1. **实拍优先**：只接受真实照片（政府/农业部门网站、权威媒体、百科实拍、产区实拍）。禁止插画、绘画、3D 渲染、AI 生成图、商品效果图冒充实拍。
2. **特征核验**：A 级每一张图必须能明确看到清单中「必须核对的特征」；B 级核验到主体特征可辨认即可。
3. **来源优先级**：政府/农业部门 > 权威媒体/百科 > 专业农业图库 > 产区企业/协会；重水印图弃用。
4. **一张一记**：每张图登记来源 URL、访问日期与核验结果。
5. **找不到就如实标记**：A 级找不到符合特征核验的图标 `pending` 并写清卡点，严禁用近似物种替代（普通鸡≠河田鸡）。
6. **命名**：垫图 `ref_{编号小写}.jpg`（如 `ref_fj120.jpg`），存 `assets/illustrations/references/`。

### 3.2 采集级别说明

- **A 级 · 必须垫图（25 种）**：特征强、易画错；每种 1–2 张，逐项核验，生成插画时必须作为参考图。
- **B 级 · 建议垫图（88 种）**：常见物产；找到可靠实拍就采 1 张（nice-to-have），找不到不阻塞。
- **C 级 · 无需垫图（7 种）**：外观常识度高，跳过。
