# Agent 任务指令：为福建物产插画采集「垫图参考实拍图」（全量版 · 120 种）

> 本指令自包含，可直接整段复制发给另一个 Agent 执行。
> 目标：为 **120 种需要绘制插画的福建物产**建立参考图库；按风险分三档采集（A 必须 / B 建议 / C 无需）。

## 0. 任务身份

你是「福建物产插画项目」的参考资料采集 Agent。为清单中全部 120 种福建物产，从网络找到真实、可靠、特征清晰的实拍照片，作为 AI 插画生成的「垫图参考」（仅形态参考，不用于发布）。

## 1. 采集级别（共 120 种：A 级 25 · B 级 88 · C 级 7）

- **A 级 · 必须垫图（25 种）**：特征强、易画错，必须为每种采集 1–2 张实拍图并逐项核验。
- **B 级 · 建议垫图（88 种）**：常见物产，找到可靠实拍就采集 1 张（nice-to-have）；找不到不阻塞，标 `optional` 即可。
- **C 级 · 无需垫图（7 种）**：外观常识度高，跳过，不采集。

## 2. 执行规则（必须遵守）

1. **实拍优先**：只接受真实照片（政府/农业部门网站、权威媒体、百科实拍、产区实拍）。禁止插画、绘画、3D 渲染、AI 生成图、商品效果图冒充实拍。
2. **特征核验**：A 级每一张图必须能明确看到清单中「必须核对的特征」；B 级核验到「主体特征」可辨认即可。
3. **来源优先级**：政府/农业部门 > 权威媒体/百科 > 专业农业图库 > 产区企业/协会。重水印图弃用。
4. **一张一记**：每下载一张图都登记来源 URL 与核验结果。
5. **找不到就如实标记**：A 级找不到符合特征核验的图标 `pending` 并写清卡点，严禁用近似物种替代（普通鸡≠河田鸡）。
6. **命名规则**：`ref_{编号小写}.jpg`（如 `ref_fj120.jpg`）；同物产第 2 张加 `_2`。

## 3. 产出物

1. 图片文件保存到 `outputs/Fujian_Terroir_Calendar_Web/assets/illustrations/references/`（若无法访问该路径，打包发回，命名不变）。
2. `MANIFEST.csv`（同目录，仅登记实际采集的图片行）：

```csv
product_id,product_name,tier,file,source_name,source_type,source_url,published_date,accessed_date,confirmed_features,verification_status,agent_note

```

2. **核验**：对照「必须核对的特征」逐项确认（必要时放大查看）；不满足就换下一张。
3. **下载**：保存高清原图（不要缩略图），按命名规则放入指定目录。
4. **登记**：在 MANIFEST.csv 写入该行。
5. **收尾**：A 级全部处理后，在 MANIFEST 末尾追加总结：A 成功数 / A pending 数及原因 / B 采集数。
