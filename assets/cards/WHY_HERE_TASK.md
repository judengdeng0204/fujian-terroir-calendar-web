# Agent 任务指令：「为什么是这里？」撰写（全量 120 种）

> 本指令自包含，可直接整段复制发给另一个 Agent 执行。
> 输入：本指令 + `product_data_pack.jsonl`（120 种物产的原有数据包）+ 第 7 节样板。
> 输出：每种物产一条「为什么是这里？」叙事（含来源与置信度）。

## 0. 任务身份

你是「福建风土物产日历」项目的内容撰写 Agent。为 **120 种福建物产**撰写详情卡中**最核心、最有辨识度**的一个板块——「为什么是这里？」。

## 1. 板块定义（写作前必读）

「为什么是这里？」**不是**风土数据的总结，也不是百科摘要。它是一段**解释物产与地方之间因果关系的叙事**：

> 为什么这样的地方，会长出/形成这样的东西？

核心逻辑：

```text
地方环境
   ↓
提供了什么条件
   ↓
这种条件如何影响物产
   ↓
最终形成了什么特征 / 地方结果
```

与「风土」严格区分：

- **风土 = 数据（事实层）**：海拔 300–600m、气候温暖湿润、年降水 1750mm、地形山地丘陵盆地……
- **为什么是这里？ = 数据之间的关系（解释层）**：这些条件为什么对这个物产重要、如何起作用。

例如，不能说：

> 古田气候温暖湿润，所以适合香菇。

而要解释：

> “温暖湿润”到底怎样作用于香菇？“林木资源”又为什么重要？

## 2. 内部准则（一句话）

> **不要告诉用户“这里有什么”，要解释“为什么这里会有它”。**

## 3. 固定写作公式（四步因果链）

每一个「为什么是这里？」都必须按以下公式写作：

```text
为什么是这里？
= ① 地方自然条件（最相关的 2–3 个，不罗列）
 + ② 物产生长/形成所需要的条件
 + ③ 两者之间的适配关系（具体因果，不是“都很好”）
 + ④ 长期的人类生产如何将这种适配固定下来
```

写作时按“三层”落笔：

**第一层｜地方条件**：一句话讲最重要的自然条件，不要全部罗列。

**第二层｜物产适配**：解释这些条件为什么适合它。

**第三层｜地方形成**：说明长期的人类生产如何把这种自然适配转化为稳定的地方物产。

## 4. 重要原则：不是“自然决定论”

不能说“因为这里下雨，所以这里有白茶”。

真正的风土是：

> **自然提供可能性，人通过长期实践把这种可能性变成物产。**

所以「为什么是这里？」的完整公式是：

> **自然条件 × 物产特性 × 人的长期实践**

三者共同作用，缺一不可。第 ④ 步（人的实践）是必须的，不能只写到自然适配就停。

## 5. 不同类型物产的重点（先判断类型，再选侧重点）

### ① 植物类
重点：**气候 + 土壤 + 水分 + 地形 + 海拔 + 光照**

示例（永春芦柑）：永春地处山地盆地之间，温暖湿润，昼夜温差和充足光照为柑橘生长提供条件；山地坡地又形成良好的排水环境，使芦柑逐渐成为当地具有代表性的果品。

### ② 茶叶
重点：**海拔 + 云雾 + 温度 + 降水 + 土壤 + 山地环境**

示例（福鼎白茶）：闽东沿海山地温暖湿润，山海之间形成的云雾环境与充沛降水，为茶树生长提供了稳定的水分与光照条件；长期形成的采摘和萎凋技艺，又将这种自然条件转化为白茶独特的风味。

### ③ 海产品
重点：**海域 + 水温 + 盐度 + 潮汐 + 洋流 + 海岸地貌**

示例（霞浦紫菜）：霞浦拥有曲折的海岸线与丰富的滩涂、浅海环境，潮汐和海水交换为紫菜生长提供条件；当地长期形成的养殖方式，又让海岸环境逐渐成为一种稳定的生产空间。

### ④ 林下 / 山野物产
重点：**森林 + 湿度 + 温度 + 土壤 + 生物环境**

示例（古田香菇）：山地湿润环境提供适宜的温湿条件，丰富的林木资源又成为传统栽培的重要基础。

### ⑤ 非农业物产（工艺 / 加工 / 陶瓷等）
重点：**原料、矿物、土壤、水、燃料、工艺传统、历史产业**

此时问题不再是“为什么它长在这里”，而是：

> **为什么这种制作方式在这里形成？**

示例（建盏）：建阳水吉一带的山丘溪谷蕴藏高铁红粘土与釉石，松柴与溪水也为龙窑烧制提供了原料和燃料；宋代以来当地窑工不断积累火候与还原气氛的控制经验，使这种矿产条件逐步转化为以兔毫、油滴著称的建盏烧制传统。

## 6. 内部标准：每个物产必须回答四个问题

1. **这里有什么特殊的自然条件？**（只找最相关的 2–4 个，不罗列全部）
2. **这种物产本身需要什么？**（喜温 / 喜湿 / 怕霜 / 特定土壤 / 潮间带 / 特定原料……）
3. **两者之间有什么具体关系？**（必须有因果解释：这个环境中的什么条件，对物产的什么特征产生了什么影响）
4. **人是怎么把这种自然优势转化成地方物产的？**（栽培 / 采摘 / 加工 / 养殖 / 工艺传统……）

## 7. 输出格式（严格遵循）

每个物产输出一个 JSON 对象，写入 `why_here_{编号小写}.json`（如 `why_here_fj053.json`），或合并为一个 `why_here_all.jsonl`（120 行）。

```json
{
  "product_id": "FJ053",
  "why_here": {
    "content": "正文 80–150 字……",
    "confidence": "high",
    "sources": [
      {"source_name": "福建日报《“菌都”养成记》", "source_type": "专业媒体",
       "source_url": "http://fjnews.fjsen.com/2024-10/13/content_31755119.htm",
       "evidence_level": "B", "quote": "香菇是古田栽培历史最悠久的食用菌，最早可追溯至隋朝年间。"}
    ],
    "reason": null
  }
}
```

字段规则：

| 字段 | 规则 |
| --- | --- |
| `content` | 正文 **80–150 字**（中文，含标点），**不超过 200 字**；无可靠资料可为 `null` + reason |
| `confidence` | `high / medium / low` |
| `sources` | 至少 1 个、最多 3 个来源；content 为 null 时为空数组 |
| `reason` | 仅 content 为空时填：`no_reliable_source` / `weak_evidence`；否则 `null` |

## 8. 写作要求与禁区

**必须：**
- 四步因果链完整：地方条件 → 物产需求 → 适配关系 → 人的实践/地方结果
- 事实只来自数据包或新检索来源，引用前核对来源
- 数字转译：不写“年均温18.5℃、年降水1750mm”，写“温暖、多雨、湿润”；精确数字留给“风土”表
- 每个物产只讲最关键的关系，不把所有风土因素塞进去

**禁止：**
- 百科摘要式写法（把数据库信息重说一遍，却没有因果解释）
- 营销空话（“品质优良”“得天独厚”“生态环境优越”）
- 自然决定论（只写自然适配，不写人的实践）
- 相邻地区类推、无来源推断、编造数字

## 9. 来源要求

1. 优先级：政府/农业部门 > 科研机构/高校 > 地方志 > 行业协会 > 专业媒体 > 专业数据库 > 商业网站/自媒体。
2. `confidence=high` 必须有多来源一致或单个 A/B 级来源直接明确。
3. 四级来源（商业网站、自媒体）不能作为唯一来源，此时 confidence 不超过 `medium`。
4. `source_url` 必须真实可访问；无法确认 URL 时用来源名称 + 出版信息，并标 `low`。
5. `quote` 只摘录支持该句的关键原文（≤80 字）。
6. 优先复用数据包 `sources_digest` 中的 A/B 级来源。

## 10. 写作样板：古田香菇（FJ053）

content：古田地处山地丘陵与盆地交错地带，温暖多雨，空气湿润，丰富的林木资源也为传统段木栽培提供了基础。这样的环境恰好满足香菇对温度、湿度和栽培基质的需求。长期以来，当地人不断调整栽培方式，使自然条件与生产经验结合，香菇也因此逐渐成为古田最具代表性的地方物产之一。

confidence：high

sources：福建日报《“菌都”养成记》（B）｜人民网福建《以菌立县》（B）｜古田县人民政府《你“造”古田的美食吗》（A）

> 对照检查：① 地方条件（山地丘陵盆地、温暖多雨、林木）✓ ② 物产需求（温度、湿度、栽培基质）✓ ③ 适配关系（环境恰好满足需求）✓ ④ 人的实践（调整栽培方式）✓

## 11. 处理流程（每物产）

1. 读数据包中该物产一行，先判断类型（植物 / 茶叶 / 海产 / 林下山野 / 非农业），按第 5 节选侧重点。
2. 整理 2–4 个最相关的自然条件（不罗列）。
3. 按四问起草：条件 → 物产需求 → 因果适配 → 人的实践。
4. 逐句对照来源核验；数字转译；控制字数。
5. 自检（第 12 节），输出 JSON。
6. 全部完成后写交付汇总。

## 12. 自检清单

- [ ] 正文 80–150 字（不超过 200），四步因果链完整
- [ ] 类型判断正确，侧重点符合该类型（海产不写成气候，非农业不写“生长”）
- [ ] 有“人的实践”这一层，不是自然决定论
- [ ] 没有百科摘要式复述、没有数据堆砌（数字已转译）
- [ ] 没有营销空话、相邻地区类推、编造
- [ ] 每条事实有来源；high 有 A/B 级或多来源支持
- [ ] URL 真实；quote ≤ 80 字；置信度如实标注

- 附汇总：完成数 / 空置数及原因 / 你认为最需要人工复核的 5 个物产及原因。
