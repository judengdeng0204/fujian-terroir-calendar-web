# Agent 任务指令：「物产与地方生活」五维撰写（全量 120 种）

> 本指令自包含，可直接整段复制发给另一个 Agent 执行。
> 输入：本指令 + `product_data_pack.jsonl`（120 种物产的原有数据包）+ 第 10 节样板。
> 输出：每种物产一个五维内容 JSON（schema 见 `living_schema.json` 与本指令第 3 节）。

## 0. 任务身份

你是「福建风土物产日历」项目的内容撰写 Agent。为 **120 种福建物产**撰写「物产与地方生活」的五维内容：**生产与技艺 / 劳作 / 饮食 / 文化 / 产业**。

## 1. 输入文件

1. `product_data_pack.jsonl`：每行一种物产，包含其原有数据（产区、地理标志、风土摘要、物候摘要、来源摘要等）。**这是你的起点信息，可优先复用，但每条复用都要再核对来源。**
2. 本指令第 10 节的「古田香菇」样板：唯一的写作范式，所有物产按此口径撰写。
3. `living_schema.json`：输出结构规范。

## 2. 核心理解：五维是一条「物产—地方生活关系链」

**不要**把这五个维度当作五个孤立的信息栏目。它们是一条完整的递进链，分别回答五个问题：

> **人怎么得到它？ → 人怎么围绕它生活？ → 人怎么吃它？ → 人怎么赋予它意义？ → 人怎么靠它生活？**

递进关系：

```text
生产与技艺  人改变物产（自然条件 → 人的知识 → 技术 → 物产）
    ↓
劳作        物产改变人的时间与劳动（谁做、何时做、如何一起做）
    ↓
饮食        物产进入人的身体与日常（吃法、保存、季节饮食）
    ↓
文化        物产开始承载地方意义（节俗、礼俗、故事、身份）
    ↓
产业        物产组织地方经济与空间（产业链、职业、市场、空间痕迹）
```

两个必须牢记的区别：

- **生产与技艺 = 怎么做**（人为了得到物产，形成了什么知识、技术、方法）
- **劳作 = 谁来做、什么时候做、怎么一起做，以及这种劳动如何组织生活**

一条铁律：

> **没有可靠证据的维度就不显示。** 一个物产可能生产与技艺很丰富、文化关系却很弱——宁可空着，也不要为了“卡片完整”硬写。

## 3. 输出格式（严格遵循）

每个物产输出一个 JSON 对象，写入 `living_{编号小写}.json`（如 `living_fj053.json`），或按批次合并为一个 JSONL。

```json
{
  "product_id": "FJ053",
  "living": {
    "production_craft": {
      "content": "正文……",
      "confidence": "high",
      "sources": [
        {"source_name": "福建日报《“菌都”养成记》", "source_type": "专业媒体",
         "source_url": "http://fjnews.fjsen.com/2024-10/13/content_31755119.htm",
         "evidence_level": "B", "quote": "香菇是古田栽培历史最悠久的食用菌，最早可追溯至隋朝年间。"}
      ],
      "reason": null
    },
    "labor": { "content": null, "confidence": "low", "sources": [], "reason": "no_reliable_source" },
    "food": { "content": "正文……", "confidence": "medium", "sources": [ ... ], "reason": null },
    "culture": { "content": null, "confidence": null, "sources": [], "reason": "weak_evidence" },
    "industry": { "content": "正文……", "confidence": "high", "sources": [ ... ], "reason": null }
  }
}
```

字段规则：

| 字段 | 规则 |
| --- | --- |
| `content` | 正文，60–120 字；无可靠资料必须为 `null` |
| `confidence` | `high / medium / low`；content 为 null 时为 `null` |
| `sources` | 每条内容至少 1 个来源；最多 3 个；content 为 null 时为空数组 |
| `reason` | 仅 content 为空时填：`no_reliable_source` / `weak_evidence` / `not_applicable`；否则为 `null` |
| 五个维度 | 独立为空，**严禁为了填满而编造** |

## 4. 字数与语言限制

1. 每维正文 **60–120 字**（中文，含标点）；五维合计不超过 **600 字**。
2. 使用**自然叙事**，像给朋友讲一个地方的物产；禁止罗列数据字段（不许出现“年均温”“海拔”“seasonal_activity”等字段名）。
3. 可以有少量数字（如“产量提高5至6倍”“生产周期缩短至8个月”），但数字必须来自来源。
4. 禁止营销腔：不要“品质优良”“远近闻名”“深受喜爱”这类空话；写成**具体的人、具体的做法、具体的时间**。
5. 每维只写一个主题，不要一段塞两个维度。

## 5. 来源要求（必须遵守）

1. **优先级**：政府/农业部门 > 科研机构/高校 > 地方志 > 行业协会 > 专业媒体 > 专业数据库 > 商业网站/自媒体。
2. 每条内容至少 1 个来源；`confidence=high` 的内容必须有多来源一致或单个 A/B 级来源直接明确。
3. **四级来源（商业网站、自媒体）不能作为关键事实的唯一来源**，只能作线索，此时 confidence 不得超过 `medium`。
4. `source_url` 必须真实可访问；无法确认的 URL 不要填，改用来源名称 + 出版信息，并把该条标为 `low`。
5. `quote` 只摘录支持该句的关键原文片段（≤80 字），不要复制整篇。
6. 优先复用数据包 `sources_digest` 中已有的 A/B 级来源；新检索的来源同样按上述规则登记。

## 6. 留空规则（最重要）

- 某一维找不到可靠资料 → `content: null` + `reason`，**不要写**。
- 禁止：用相邻地区、同类物种、通用常识补全（如“同为食用菌之乡的 X 县…”）；禁止把营销宣传当事实；禁止自行推断数字。
- **文化维度大量为空是正常且正确的**——只有少数物产有可查的节庆、礼俗、传说。
- 若资料存在冲突，保留主要说法并在 `reason` 或交付汇总中注明“存在冲突”，不要强行抹平。

## 7. 五维写作指南（逐维详解）

### 7.1 生产与技艺（人怎么得到它？）

回答：**人是怎么获得、培育、制作和加工这种物产的？** 这是“人对物产的主动塑造”。

“生产”不要狭义理解成农业生产，而是覆盖一个物产从自然资源变成“地方物产”的**整个技术过程**。

可以包含：

- **生长阶段**：栽种、培育、育种、养殖、放牧、林下经营、水产养殖、土壤管理、灌溉、病虫害管理
- **采集阶段**：采摘、采挖、捕捞、狩猎、采集、挑选
- **加工阶段**：萎凋、发酵、晒制、烘焙、腌制、脱水、熏制、炮制、酿造
- **技术与知识**：当地独特的生产方法、对天气/温度/湿度的判断、对成熟度的判断、特殊工具、特殊生产设施、师徒传承、地方经验

它真正要寻找的不是“这个产品是怎么生产的”，而是：

> **“当地人为了适应这个地方，发展出了什么特殊的方法来获得它？”**

叙事链：**自然条件 → 人的知识 → 技术 → 物产**

示例（福鼎白茶）：福鼎的白茶制作并不以复杂的揉捻和炒制为核心，而是通过萎凋与干燥，让茶叶在较少人为干预的情况下完成风味转化。这种制作方式与当地湿润、多云雾的环境以及长期形成的制茶经验共同构成了白茶的地方性。

### 7.2 劳作（人怎么围绕它生活？）

回答：**这种物产如何进入当地人的劳动和日常生活？**

与“生产与技艺”严格区分：**生产与技艺 = 怎么做；劳作 = 谁来做、什么时候做、怎么一起做，以及这种劳动如何组织生活。**

可以包含：

- **时间**：什么季节最忙？何时开始准备？何时采收？是否存在短暂的最佳窗口？是否形成明显的季节性劳动？
- **人**：谁参与？家庭成员如何分工？男女、老少分工？是否存在专业工匠？
- **劳动方式**：手工还是机械？家庭生产还是合作社？小规模还是规模化？是否需要临时劳动力或季节性雇工？
- **劳动节奏**：是否形成特殊“忙季”？是否影响作息？是否改变村庄人口流动、学校与家庭生活？

示例（古田香菇）：从菌棒制作、接种培养到出菇、采收和烘干，香菇生产形成了一套连续的劳动链条。不同阶段对应不同的劳作强度，也让香菇生产成为许多家庭长期参与的地方性生产活动。

> 这里讲的不是“怎么种香菇”，而是“**香菇如何进入人的时间表**”——这与“物产日历”的季节叙事直接相关。

### 7.3 饮食（人怎么吃它？）

回答：**这种物产进入当地人的嘴里之后，改变了什么？**

研究链条：**物产 → 食物 → 饮食习惯 → 地方味觉**。不要只写“可以怎么吃”。

可以包含：

- **食用方式**：鲜食、干制、腌制、发酵、炖煮、烘烤、蒸制、泡茶、酿酒
- **地方菜**：代表性菜肴、地方小吃、家庭食谱、宴席菜、街头食物
- **季节饮食**（尤其重要）：春天吃什么？什么时候最鲜？为什么这个季节必须吃它？
- **保存方式**（人对季节性的回应）：鲜笋→笋干、鲜鱼→鱼干、茶叶→制茶、水果→果脯

示例（古田香菇）：鲜香菇适合即时烹饪，而干香菇通过脱水延长了保存时间，使一种具有明显生长季节的山地物产进入全年饮食；香菇因此不仅是一种食材，也成为汤、炖菜和宴席中稳定出现的地方味道。

### 7.4 文化（人赋予它什么意义？）

回答：**当一个物产陪伴一个地方足够久，它有没有开始承载意义？**

这是最容易写空的一维，**禁止**泛泛写“当地人非常喜爱这种物产”。

真正需要寻找的是它有没有进入：

- **节俗**：春节、清明、中秋、丰收节、婚礼、祭祀
- **礼俗**：送礼、待客、婚嫁、拜访、长辈馈赠
- **地方故事**：传说、民间故事、历史事件、名人故事
- **地方艺术**：图案、民歌、民谣、摄影、文学、工艺
- **地方身份**：为什么当地人会说“这是我们的东西”？为什么它成为地方名片？外地人为什么通过它认识这个地方？

判断标准：**物产是否已超越它作为食物/原材料的实用功能，成为一种地方意义。**

示例（福鼎白茶）：不仅是茶，还可能进入茶礼、待客、礼赠、茶文化与地方身份。（漳州水仙花则可能进入年节赏花、家庭装饰、花市与地方花卉文化。）

### 7.5 产业（人怎么靠它生活？）

回答：**当一种物产变得足够重要，它如何改变一个地方的经济和社会结构？**

从“人怎么种它”进入“**一个地方怎么围绕它运转**”。

可以包含：

- **产业链**：种植 → 采收 → 加工 → 包装 → 运输 → 批发 → 零售
- **职业**：专业种植户、工匠、加工者、收购商、经销商、运输者、市场经营者
- **市场**：集市、专业市场、批发市场、电商、产地交易
- **地方经济**：是否成为支柱产业？是否影响收入？是否带动加工与产业集群？
- **地方空间**（特别重要）：物产有没有改变地理空间——菇棚、茶园、晒场、花卉市场、加工厂、专业村。这与地图叙事直接相关，写产业时尽量留意“空间痕迹”。

## 8. 每物产检索任务：五组搜索（不要笼统搜“人文关系”）

对每个物产，按五个维度分别检索。以“古田香菇”为例：

```text
古田香菇 + 栽培技术 / 制作技术 / 加工技术
古田香菇 + 劳作 / 采收 / 季节 / 农户
古田香菇 + 饮食 / 菜肴 / 食用 / 保存
古田香菇 + 民俗 / 文化 / 地方记忆 / 地方身份
古田香菇 + 产业 / 市场 / 经济 / 产业链
```

把“{物产名}”替换成目标物产即可。检索结果按第 5 节来源要求登记。

## 10. 写作样板：古田香菇（FJ053）

> 以下为唯一范式：叙事、有来源、字数合规、维度留空规则正确。

### 生产与技艺

content：香菇是古田栽培历史最悠久的食用菌，可追溯至隋朝；早先菇农进山伐阔叶树段木栽培，每百斤段木仅产约 1.8 斤干菇。20 世纪当地菇农探索出袋料菌棒栽培，生产周期从 2—4 年缩短至约 8 个月，形成后来全国推广的“古田模式”。

confidence：high

sources：福建日报《“菌都”养成记》（B）｜宁德新闻网·彭兆旺袋料栽培报道（B）

### 劳作

content：从菌棒制作、接种培养到出菇、采收和烘干，香菇生产形成了一套连续的劳动链条。不同阶段对应不同的劳作强度，也让香菇生产成为许多家庭长期参与的地方性生产活动。

confidence：medium

sources：福建日报《“菌都”养成记》（B）

### 饮食

content：鲜香菇适合即时烹饪，而干香菇通过脱水延长了保存时间，使一种具有明显生长季节的山地物产进入全年饮食；香菇因此不仅是一种食材，也成为汤、炖菜和宴席中稳定出现的地方味道。

confidence：medium

sources：古田县人民政府《你“造”古田的美食吗》（A）｜澎湃新闻·福闻话（B）

### 文化

content：种菇食菇的传统让香菇进入古田的地方记忆：民间文献记载了香菇入药的历史，菌菇全席被赋予“清虚合和”的意涵，“中国食用菌之都”的称号则让香菇成为外地认识古田的入口。

confidence：medium

sources：澎湃新闻·福闻话（B）｜闽都网·古田菇宴（C）

### 产业

content：古田食用菌产业源起环翠屏湖区域，20 世纪 60 年代起先后掀起银耳、香菇等“五次浪潮”，菇棚与烘干设施遍布村镇，形成从菌种、栽培、加工到销售的“县域工厂化”产业链；2023 年全县食用菌鲜品产量 92 万吨、全产业链产值 255 亿元，香菇是其中历史最悠久的品种。

confidence：high

sources：人民网福建《以菌立县》（B）｜福建日报《“菌都”养成记》（B）

> 说明：样板中 confidence 与 source 等级为撰写示例，交付时请按你实际核验的来源重新判定。
